# AI助教答疑平台课后任务提交说明

## 一、任务完成情况

本项目在 VS Code 类型的代码编辑环境中，通过多轮需求拆分、页面实现、浏览器验证和文档整理完成。最终交付内容包括：

- 个性化注册页面：`register.html`
- 个性化登录页面：`login.html`
- 与作业参考图一致的答疑工作台：`app.html`
- 公共样式与交互脚本：`assets/`
- 登录页、注册页、答疑页截图：`docs/screenshots/`
- 全过程对话记录：`docs/多轮对话过程.html`

## 二、个性化注册与登录设计

### 注册页

注册页不是只收集用户名和密码，而是根据学习场景做了个性化：

- 使用身份单选项区分学生与教师。
- 使用学院下拉列表绑定课程资源范围。
- 使用兴趣标签收集程序设计、Web 开发、人工智能等方向。
- 使用文件输入选择头像，并在本机即时预览。
- 使用 `meter` 展示密码强度，共四级反馈。
- 注册成功后跳转登录页，账号数据保存在当前浏览器。

### 登录页

登录页支持用户名或邮箱登录，并为重复登录提供“记住我的账号”选项。密码输入框提供显示与隐藏按钮，错误信息通过 `aria-describedby` 与输入控件关联。

## 三、使用的 HTML5 表单增强

| 能力 | 使用位置 | 作用 |
| --- | --- | --- |
| `required` | 注册、登录、提问表单 | 阻止空值提交 |
| `pattern` | 用户名、学号、密码 | 在浏览器端完成格式约束 |
| `minlength` / `maxlength` | 姓名、密码、问题 | 限制有效长度 |
| `type=email` | 注册邮箱 | 使用浏览器内置邮箱校验 |
| `autocomplete` | 姓名、用户名、邮箱、密码 | 支持密码管理器与自动填充 |
| `inputmode` | 邮箱、学号 | 在移动端显示更合适的键盘 |
| `autocapitalize` / `spellcheck` | 用户名、邮箱 | 避免自动首字母大写和拼写干扰 |
| `fieldset` / `legend` | 学习身份、兴趣方向 | 建立清晰的表单语义分组 |
| `meter` | 密码强度 | 表示 0 至 4 的有限范围值 |
| `output` | 密码强度、问题字数 | 显示计算结果 |
| `FormData` | 注册提交 | 统一读取姓名、身份、兴趣等字段 |
| `validity` | 所有核心表单 | 判断缺失、长度、格式等原生状态 |
| `setCustomValidity()` | 密码确认、账号重复 | 增加业务层校验 |
| `reportValidity()` | 注册、登录、提问 | 调用浏览器原生错误提示 |
| `accept` / `FileReader` | 头像、答疑附件 | 限制文件类型并进行本地预览 |

## 六、Gitee 推送

项目根目录已经初始化为 Git 仓库，默认分支为 `main`。完成 Gitee 仓库创建后，在项目目录执行：

```powershell
git remote add origin https://gitee.com/你的用户名/ai-teaching-qa-platform.git
git push -u origin main
```

推送后，将实际仓库链接补充到本文档和作业提交页即可。

## 七、检查说明

- 项目不依赖外部 CDN，断网也可以打开页面。
- 注册、登录、对话记录均使用浏览器本地存储，不需要后端。
- 第 9 周接入真实 AI 接口时，只需将 `assets/js/app.js` 中的 `answerFor()` 替换为接口请求。
